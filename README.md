# Louscoot

Application de location de scooters développée en Java dans le cadre d'un projet de L2 Informatique à l'Université d'Évry Val d'Essonne.


## Présentation

Louscoot simule la gestion d'une agence de location de scooters. L'application propose deux espaces distincts : un espace client pour consulter et réserver des véhicules, et un back-office gestionnaire pour administrer le parc.


## Fonctionnalités

**Côté client**
- Consultation de la liste des scooters disponibles
- Filtres par prix, couleur, marque, modèle, disponibilité et motorisation
- Sélection d'un scooter et saisie d'une durée de location
- Affichage des détails du véhicule (marque, modèle, type de permis requis)

**Côté gestionnaire**
- Ajout de marques, modèles et scooters
- Gestion des employés
- Gestion des retours avec état des lieux et affectation à un employé


## Stack technique

- Java (POO)
- Interface graphique Swing (JFrame, JPanel, JList, JComboBox)
- Architecture MVC
- Collections Java (Vector)
- Gestion des dates avec LocalDate


## Lancer le projet

1. Cloner le repo
2. Ouvrir dans un IDE Java (IntelliJ, Eclipse...)
3. Lancer `Main1.java`
